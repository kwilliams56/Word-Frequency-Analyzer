# Word Frequency Analyzer

A C++ program that analyzes text files and counts word frequencies using a symbol table data structure.

## Features
- Word frequency counting
- Text normalization
- File input processing
- Sorting by frequency
- Performance timing metrics

## Technologies Used
- C++
- Symbol Tables
- STL
- File I/O
- Sorting Algorithms
## What I Learned

This project helped me improve my understanding of:

Symbol tables
Text processing
File handling
Sorting algorithms
Performance measurement
Data organization in C++
